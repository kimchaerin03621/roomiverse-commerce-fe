# ROOMi (ROOMiVERSE) website

Graduation-exhibition site for the DJ lifestyle brand **ROOMi**. Next.js 16 (App Router, TypeScript, CSS Modules).

- **`main`**: the current, final version (this one).
- **`codex-version`**: the earlier Vite + React version made with Codex, kept for reference.

```bash
npm install
npm run dev      # http://localhost:3000
```

Notes
- Commerce and party inquiries are a simulator (nothing is paid or booked); records live in the browser (localStorage).
- Party-name fonts come from Noonnu. The font files are not in this repository; the CSS loads them from Noonnu's official web-font addresses.
