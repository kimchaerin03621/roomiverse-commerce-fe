# 컨펌 발표 순서 (사용자 행동 중심)

교수님이 보는 것: 기능 목록이 아니라 **사용자가 이 사이트에 들어와서 무엇을 하고, 어떤 서비스를 누리는가.**
가장 중요한 페이지는 **What's Going On**. 시간의 절반 이상을 여기와 Let's Party에 쓴다.

한 줄 틀: **"사용자는 파티를 고르고, 내 공간에 맞춰 예약하고, 필요한 장비를 사서, 어디서든 평범한 공간을 파티 공간으로 바꾼다."**

## 흐름 (총 약 5분, 시간은 조절)

| # | 페이지 | 시간 | 사용자가 하는 행동 | 사용자가 얻는 것 (말로 할 문장) |
|---|---|---|---|---|
| 0 | (말만) | 10초 | - | "ROOMi는 장비, 공간 구성, 세팅이 부담스러운 사람도 어디서든, 누구와든 원하는 파티를 열 수 있게 해 주는 서비스예요." |
| 1 | 인트로 → 3D 샵 | 30초 | 컨테이너를 눌러 안으로 들어간다. 안을 둘러보고, 조명을 바꾼다. | "컨테이너가 열리면 파티 공간이 있어요. 여기서 사용자는 파티의 분위기를 먼저 체험해요." (오래 머물지 않는다) |
| 2 | Meet ROOMi | 30초 | 스크롤하며 ROOMi가 뭔지 본다. | "Play, Immersion, Expansion. 이 서비스가 왜 있는지 한눈에 알 수 있어요." (읽지 말고 Value 3개만 짚기) |
| **3** | **What's Going On** | **2분** | 6가지 파티 중 나와 닮은 파티를 고른다. 파티 상세에서 필요한 공간, 인원, 전력을 보고 준비물과 추가 옵션을 확인한다. | "어떤 파티를 열지 모르는 사람도 여섯 장면을 보면 고를 수 있고, **내가 뭘 준비하면 되는지**를 상세에서 바로 알 수 있어요." |
| **4** | **Let's Party** | **1분** | 파티 상세에서 "Let's Party"를 눌러 4단계(파티, 날짜·장소, 공간 확인, 연락처)로 예약한다. 예약번호를 받는다. | "고른 파티가 그대로 이어져서, 정보만 채우면 예약이 끝나요. 나머지 세팅은 ROOMi가 해요." |
| 5 | Shop → Cart → My | 40초 | 장비나 굿즈를 담아 주문한다. My에서 주문번호, 예약번호로 내역을 조회한다. | "파티에 필요한 장비와 굿즈를 같은 곳에서 사고, 예약과 주문을 한 곳에서 확인해요." |
| 6 | 마무리 | 15초 | - | "고르고, 예약하고, 세팅받고, 즐긴다. 어디든 내 우주가 돼요." |

## 시연 요령 (What's Going On)
- GNB의 What's Going On에서 시작. 핑크 띠지(01~06)를 눌러 장면 사이를 빠르게 이동해서 "여섯 가지 중에 고른다"는 느낌을 준다.
- 상세는 **Rave Party** 하나를 깊게 (어두운 풀블리드라 인상이 강함). Requirements → Essentials → Add-ons 순서로 "내가 준비할 것"만 짚는다.
- 다른 파티(예: Day Party)는 띠지로 한 번만 넘겨서 분위기가 다르다는 것만 보여 준다.
- 상세 맨 아래 "LET'S PARTY" 띠로 곧바로 예약으로 넘어간다 (파티가 미리 선택돼 있음).

## 시연 요령 (Let's Party)
- 미리 정한 값으로 진행: Rave Party / 11–20명 / Techno / 날짜 / 주소 / Apartment / 이름 등. 빈 칸 검증은 말로만 언급.
- 예약번호가 나오면 "My에서 이 번호로 다시 조회돼요"로 5번과 연결.

## 발표 전 점검
- 개발 서버 대신 빌드해서 띄우기: `npm run build` 후 `npm start` (개발 서버는 첫 페이지 컴파일이 느림). 띄운 뒤 인트로 → 3D 샵을 한 번 미리 돌려 두기.
- 장바구니는 새로고침하면 비워짐. 시연 중에 새로고침하지 않기.
- 시연용 브라우저의 기록(localStorage)은 지워 두기 (My가 깨끗하게 시작).
- 가격은 예시, 결제와 예약은 시뮬레이터라는 말을 한 번만 하기 (화면에도 "Exhibition demo" 표시).
- 3D 샵 상품 이미지는 임시(3D 모델 렌더). 실물 사진이 없다는 질문에 대비: "제품디자인 프로젝트의 컨트롤러가 들어갈 자리예요."

## 질문 대비
- "What's Going On에 더 들어갈 게 있나요?" → 6가지 파티 외에 콘텐츠 2개가 더 들어올 예정(각자 이름이 있음). 지금은 파티 6개가 중심.
- "예약하면 뭘 해 주나요?" → 장비 반입, 공간 세팅, 조명과 사운드 설치까지 ROOMi가 해 준다는 서비스 설명 (파티 상세의 Essentials, Add-ons가 그 내용).
